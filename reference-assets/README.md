# reference-assets

Reference material used while building the miniature 3D scenes in `homepage/explorer` (Education island) and `homepage/experience` (Experience planet). The site does not load anything from this folder.

## character/
- `kenney-space-kit/`: Kenney "Space Kit" 2.0, CC0 (see its `License.txt`). Only the licence, previews and the two astronaut models (`Models/GLTF format/astronautA.glb`, `astronautB.glb`) are committed; the rest of the kit (about 1,700 files) is git-ignored. Re-download it from https://kenney.nl/assets/space-kit if needed.
- The site's player is a procedural astronaut built in code (`homepage/world/astronaut.js`), so these models are reference only.

## buildings/
Three photos per place from Wikimedia Commons, saved at ~1600px wide. Author and licence for each file are in that folder's `SOURCES.txt` (mostly CC BY-SA, so keep attribution if you reuse them).
- `svnit-surat/`, `sorbonne-chapel/`, `observatoire-de-paris/`, `glasgow-gilbert-scott/`, `iit-indore/`, `aei-hannover/`

Note: `svnit-surat-1.jpg` and `-2.jpg` are skyline shots; `-3.jpg` is the main gate.
